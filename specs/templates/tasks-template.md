## Task Format Reference

> **AI Instructions - Task Format**:
> - Every task follows this exact format for parsing compatibility
> - Task ID is sequential: T001, T002, T003...
> - [P] marks tasks that can run in parallel (different files, no dependencies)
> - {US_N} links task to user story from spec.md
> - Description includes exact file path for implementation
> - Avoid: vague descriptions, missing file paths, dependencies within [P] tasks

**Format**: `- [ ] T{NNN} [P?] {US_N} Description | path/to/file.ext`

| Component | Required | Description |
|-----------|----------|-------------|
| `T{NNN}` | Yes | Sequential task ID (T001, T002...) |
| `[P]` | Optional | Parallelizable - no dependencies on other [P] tasks in same phase |
| `{US_N}` | Optional | Links to User Story N from spec.md |
| Description | Yes | Clear action: verb + what + where |
| File path | Yes | Exact path where change happens |

**Examples**:
- `- [ ] T001 [P] Create project structure | package.json`
- `- [ ] T005 {US1} Implement user model | src/models/user.ts`
- `- [ ] T012 [P] {US2} Add validation for input | src/validators/input.ts`
